# Как отдать дашборд

Порядок: ссылка, если среда это умеет, иначе — HTML-файл. Файл работает всегда.

## Claude (claude.ai и приложение)

1. Создай дашборд как артефакт — это готовая страница прямо в чате.
2. Подскажи пользователю, как получить ссылку:
   - тарифы Free, Pro, Max: открыть артефакт → «Publish» → скопировать ссылку.
     Ссылку открывает любой, у кого она есть, без аккаунта Claude;
   - тарифы Team и Enterprise: «Share & copy link» — ссылка работает только внутри организации.
3. Если ссылка не нужна — предложи файл: скачать артефакт из его окна или, если такой кнопки
   нет, сохранить код как `pulse.html` (см. «Другие чаты»).

Важно знать:
- Остаётся ли ссылка прежней после обновления дашборда, справка Anthropic не говорит. После
  «обнови пульс» проверь ссылку. Если появилась новая — перешли коллегам новую.
- После «Unpublish» тот же артефакт опубликовать снова нельзя — только создать новый.
  Не снимай публикацию ради обновления.

## ChatGPT

1. Открой дашборд в canvas (это окно рядом с чатом, где видно страницу и код).
2. Подскажи поделиться через кнопку «Поделиться» на панели canvas — по справке OpenAI так можно
   поделиться отрисованной HTML-страницей, как чатом. Доступно на всех тарифах.
3. Если canvas недоступен — по справке OpenAI он не работает в моделях GPT-5.5 и новее —
   или получатель видит код, а не страницу: отдай дашборд файлом (как для других чатов).

## Другие чаты (DeepSeek и др.)

1. Выдай HTML-код целиком, одним блоком.
2. Подскажи: создать на компьютере файл `pulse.html` (например, в Блокноте: «Сохранить как» →
   тип «Все файлы» → имя `pulse.html`), вставить код, сохранить.
3. Файл открывается двойным щелчком в браузере, на телефоне — из мессенджера или почты.
   Его можно переслать коллегам.

## Предупреждение — один раз

- Опубликованную ссылку может открыть любой, у кого она есть. Не пересылай её за пределы
  компании. Если в дашборде чувствительные данные — лучше отдать файлом.
- Сайты Claude и ChatGPT из России без VPN могут не открываться — у коллег без VPN ссылка
  не сработает. Тогда отдай дашборд HTML-файлом: его можно переслать в мессенджере или по почте,
  он открывается в любом браузере без интернета.
