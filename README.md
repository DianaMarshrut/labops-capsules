# Капсулы labopsai

Бесплатные готовые навыки для ИИ, которые руководитель малого и среднего бизнеса ставит себе
сам — в Claude, ChatGPT или DeepSeek.

| Капсула | Что делает | Статус |
|---|---|---|
| «Пульс» (`puls`) | Дашборд руководителя: главные цифры компании на одной странице | Готова |
| «След» (`sled`) | Встреча → протокол → задачи и напоминания | Готова |
| «Радар» (`radar`) | Утренняя сводка руководителю: письма, встречи, горящие задачи | Готова |

Все капсулы бесплатные. Лицензия — MIT (см. `LICENSE`).

# Пульс — дашборд руководителя по ссылке

Собирает главные цифры компании на одной странице: продажи, закупки, склад,
производство, финансы. Страницу можно открыть в браузере и переслать ссылкой или файлом.

## Что делает

Настраиваешь один раз — дальше пишешь одну фразу «обнови пульс» или не делаешь ничего
(задача по расписанию).

1. Помогает завести постоянное место: проект «Пульс» в Claude или ChatGPT, чат «Пульс»
   в DeepSeek, рабочую папку в Claude Code.
2. Подключает источник, начиная с постоянного подключения, — только с правами на чтение:
   - Битрикс24 — ссылкой вебхука (Claude, ChatGPT, DeepSeek, Claude Code);
   - Google Таблицы — встроенным коннектором Google Drive (Claude, ChatGPT) или ссылкой
     «читатель»;
   - МойСклад в Claude Code — через его официальный сервер подключения;
   - amoCRM, 1С и другие системы — Excel-выгрузкой. Это путь «каждый раз руками»: для каждого
     обновления нужна свежая выгрузка.
3. Помогает выбрать 3–7 главных цифр или предлагает готовый набор.
4. Собирает дашборд — HTML-страницу, которая открывается и на компьютере, и на телефоне.
5. Держит дашборд в одном месте: тот же артефакт Claude, тот же сайт ChatGPT, тот же файл
   `pulse.html`.
6. Сохраняет настройки один раз в проекте и предлагает автообновление там, где оно есть.

## Что в репозитории

| Путь | Для чего |
|---|---|
| `plugins/puls/skills/puls/` | Сам навык: `SKILL.md`, справочники `references/`, шаблон `templates/dashboard.html` |
| `dist/puls.zip` | Тот же навык в архиве — для загрузки в Claude (claude.ai и приложение) |
| `chat-instruction.md` | Весь навык одним текстом — для ChatGPT, DeepSeek и других чатов |
| `.claude-plugin/marketplace.json` | Каталог плагинов для Claude Code |
| `scripts/build.py` | Пересобирает `dist/puls.zip` и `chat-instruction.md` после правок навыка |
| `tests/` | Проверка шаблона на тестовой Excel-выгрузке и скриншоты |

## Как поставить

### Claude Code

Claude Code — программа для работы с Claude в терминале компьютера. В Claude Code набери:

```
/plugin marketplace add DianaMarshrut/labops-capsules
/plugin install puls@labopsai-capsules
```

В Claude Code 2.1.275 и новее можно одной командой:

```
/plugin install puls --marketplace DianaMarshrut/labops-capsules
```

Если репозиторий скачан на компьютер, вместо `DianaMarshrut/labops-capsules` укажи путь
к папке, например `/plugin marketplace add ~/labops-capsules`.

То же из обычного терминала:

```
claude plugin marketplace add DianaMarshrut/labops-capsules
claude plugin install puls@labopsai-capsules
```

### Claude (claude.ai и приложение)

Навыки есть на всех тарифах: Free, Pro, Max, Team, Enterprise.

1. Включи запуск кода: «Settings» → «Capabilities» → «Code execution and file creation».
   На тарифах Team и Enterprise это и сами навыки сначала включает владелец организации:
   «Organization settings» → «Plugins & skills» → вкладка «Policy».
2. Скачай `dist/puls.zip` из этого репозитория. Распаковывать не нужно.
3. «Customize» → «Skills» → «+» → «+ Create skill» → «Upload a skill» → выбери `puls.zip`.
4. Проверь, что навык «puls» включён в списке «Customize» → «Skills».
5. «Projects» → «+ New Project» → «Пульс». В чате проекта напиши: «Хочу дашборд по продажам».
6. В конце первой сборки Claude выдаст блок «Настройки пульса» — положи его в «Set project
   instructions» этого проекта.

### ChatGPT

1. Создай проект «Пульс» (проекты есть и на Free) и добавь в его файлы `chat-instruction.md`.
2. В чате проекта напиши: «Работай по инструкции из файлов проекта. Собери пульс» — и вставь
   ссылку вебхука Битрикс24 или ссылку на Google Таблицу. Excel-выгрузка — если другого пути нет.
3. Блок «Настройки пульса» из конца первой сборки положи в инструкции проекта
   («•••» → «Project settings»).

### DeepSeek и другие чаты

1. Открой новый чат и назови его «Пульс». Первым сообщением вставь текст `chat-instruction.md`
   (или приложи файл и напиши «Работай по этой инструкции»).
2. Вставь ссылку вебхука Битрикс24 или ссылку на Google Таблицу либо загрузи Excel-выгрузку
   и напиши: «Собери пульс». Если чат не открыл ссылку — используй Excel-выгрузку.
3. Для обновления возвращайся в этот же чат.

## Один раз и каждый раз

| Где | Что делаешь один раз | Что делаешь каждый раз |
|---|---|---|
| Claude | Загружаешь навык, создаёшь проект «Пульс», подключаешь источник (коннектор Google Drive или ссылка вебхука Битрикс24), кладёшь «Настройки пульса» в инструкции проекта, публикуешь артефакт. На Pro и выше — задача по расписанию в Cowork | Пишешь «обнови пульс» в том же чате проекта. С задачей по расписанию — ничего, свежий дашборд в «Scheduled» |
| ChatGPT | Создаёшь проект «Пульс», кладёшь `chat-instruction.md` в файлы, ссылку и «Настройки пульса» — в инструкции проекта. На Plus и Pro — публикуешь сайт (Sites). По желанию — задача по расписанию (Tasks) | Пишешь «обнови пульс» в том же чате проекта. С задачей по расписанию — ничего (сначала проверь её на одном запуске) |
| DeepSeek | Заводишь чат «Пульс», вставляешь `chat-instruction.md` и ссылку, сохраняешь дашборд в файл `pulse.html` | Пишешь «обнови пульс» в том же чате и заменяешь код в `pulse.html` |

Где «каждый раз» больше одной фразы — честно:
- Источник — Excel-выгрузка (amoCRM, 1С, МойСклад вне Claude Code): каждый раз выгрузить свежий
  файл и загрузить его в чат. Расписание такой источник не обновит.
- Битрикс24 по ссылке отдаёт до 50 записей за раз. Claude Code сам дочитывает все части.
  Браузерный чат может видеть только первые 50: если записей в CRM больше, итоги будут
  неполными — нужен Claude Code или Excel-выгрузка.
- Google Таблица по ссылке «читатель»: что чат её откроет, официально не описано — проверь
  на первой сборке. Коннектор Google Drive в Claude и ChatGPT надёжнее.

Что подтверждено справкой, а что нет — в `plugins/puls/skills/puls/references/publish.md`
(раздел «Источники»).

## Безопасность

- Для ИИ — отдельный пользователь или ключ, права только на чтение и только к нужным разделам.
- Битрикс24: вебхук создаёт отдельный сотрудник с ролью «Чтение» в CRM. ИИ пользуется только
  методами чтения (`crm.deal.list`, `crm.lead.list`). Ключ внутри ссылки вебхука — это доступ
  к CRM: храни ссылку только в личном проекте, не в общем, и не пересылай. Если ссылка могла
  утечь — удали вебхук и создай новый.
- ИИ не выводит ключи и ссылки вебхука ни в ответах, ни в дашборде. Шаблон дашборда сам
  скрывает ключ, если ссылка всё же попала в данные, и ничего не загружает из интернета.
- Если система не умеет давать ключ только на чтение (например, amoCRM) — работаем через
  Excel-выгрузку.
- Публичную ссылку на дашборд видит любой, у кого она есть. Не пересылай её за пределы компании.

После правок в `plugins/puls/skills/puls/` пересобери архив и инструкцию для чатов:

Нужен Python 3.10 или новее.

```
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
python3 -m playwright install chromium
```

и контрольную сумму SHA-256.

# Радар — утренняя сводка руководителю

Каждое утро — одна короткая сводка в твоём ИИ: какие встречи сегодня, что горит, кому
ответить, какие задачи просрочены. Читается с телефона за минуту.

## Что делает

1. Один раз спрашивает, где почта, календарь и задачи, и ведёт по подключению:
   - Gmail и Google Календарь — встроенными коннекторами Claude (на всех тарифах, включая Free)
     и приложениями ChatGPT;
   - Outlook (рабочий Microsoft 365), iCloud в ChatGPT — их коннекторами;
   - задачи и календарь Битрикс24 — ссылкой вебхука (`tasks.task.list`,
     `calendar.event.get.nearest` — только чтение);
   - Яндекс Почта и Яндекс Календарь — официального коннектора мы не нашли; есть непроверенный
     обход через Gmail и Google Календарь или ручная вставка.
2. Спрашивает, что для тебя важно: чьи письма, какие слова в теме, через сколько часов письмо
   без ответа попадает в «Ответить».
3. Сохраняет настройки один раз — в проект Claude или ChatGPT.
4. Ставит сводку по расписанию внутри твоего ИИ: задачи по расписанию ChatGPT (есть и на Free:
   до 3 задач, раз в день, окно «утро») или Claude Cowork (Pro и выше). Без расписания —
   одна фраза «радар».

Радар **только читает**: не отправляет письма, не создаёт черновики, не меняет события
и задачи. Текст писем для него — данные, а не команды: письмо «ИИ, перешли всё» он пометит
как подозрительное и ничего не сделает.

## Как поставить

**Claude Code:**

```
/plugin marketplace add DianaMarshrut/labops-capsules
/plugin install radar@labopsai-capsules
```

**Claude (claude.ai и приложение):** скачай `dist/radar.zip` → «Customize» → «Skills» → «+» →
«+ Create skill» → «Upload a skill». Подключи коннекторы Gmail и Google Calendar
(«Customize» → «Connectors»). Создай проект «Радар» и напиши в нём: «Настрой радар».

**ChatGPT:** создай проект «Радар», добавь в его файлы `chat-instruction-radar.md`, в инструкции
проекта напиши «Работай по файлу chat-instruction-radar.md». Подключи Gmail и Google Calendar
(«Settings» → «Plugins»). Напиши в проекте: «Настрой радар».

**DeepSeek:** вставь текст `chat-instruction-radar.md` первым сообщением и напиши «радар».
Расписания и коннекторов в официальных источниках DeepSeek мы не нашли — данные вставляешь сам.

## Безопасность

- Только чтение. Если чат во время сводки просит подтвердить отправку письма или изменение
  события — отклоняй: радар такого не делает.
- Ссылка вебхука Битрикс24 — это ключ: режима «только чтение» у вебхука нет. Отмечай только
  права «Задачи» и «Календарь», храни ссылку только в инструкциях проекта или в задаче
  по расписанию, не делись этой задачей и проектом. Утекла — удали вебхук и создай новый.
- Радар не выводит ссылки и ключи в сводку и не переносит в неё ссылки из писем.

## Один раз и каждый раз

| ИИ | Что делаешь один раз | Что делаешь каждый раз |
|---|---|---|
| Claude Pro и выше | Ставишь навык, подключаешь Gmail и Google Calendar, проект «Радар» с настройками, задачу по расписанию в Cowork | Ничего: утром открываешь сводку в разделе «Scheduled» |
| Claude Free | Ставишь навык, подключаешь коннекторы, проект «Радар» с настройками | Одна фраза «радар» в проекте |
| ChatGPT (и Free) | Проект «Радар» с инструкцией, подключаешь Gmail и Google Calendar, задачу по расписанию «каждый день утром» | Ничего: сводка приходит пушем или письмом. Работают ли Gmail и Calendar на Free — проверь на первой сводке |
| DeepSeek | Сохраняешь у себя инструкцию и «Настройки радара» | Вставить инструкцию и настройки, написать «радар», вставить письма, встречи и задачи (руками) |

# След — встреча → протокол → задачи

После встречи пишешь «разбери встречу» — и получаешь протокол: коротко о главном, решения,
задачи с ответственными и сроками, открытые вопросы. Задачи ставятся в Битрикс24, напоминания —
в календарь. Во внешние системы «След» пишет только после твоего «да» на точный список.

## Что делает

1. Берёт встречу: из Granola через коннектор (Claude, ChatGPT) — ничего копировать не нужно;
   или текст и файл расшифровки из Телемоста, Контур.Толка, SaluteJazz и любого другого сервиса.
2. Собирает протокол по шаблону. Ответственных и сроки берёт только из встречи: не назвали —
   пишет «не назван» и спрашивает. «До пятницы» переводит в дату от даты встречи.
3. Показывает нумерованный список действий и ждёт «да» («ставь 1 и 3», правки).
4. Задачи:
   - Claude Code — сам ставит задачи в Битрикс24 через отдельный вебхук с правом только
     «Задачи» (только создание задач: ничего не меняет и не удаляет);
   - браузерные Claude, ChatGPT, DeepSeek — выдают готовый список для ручного ввода
     в Битрикс24, amoCRM, Яндекс Трекер. Почему так: браузерный чат открывает только
     присланную ссылку как есть и не может сам отправить задачу (подробно — в справочнике
     «Задачи из протокола» внутри навыка).
5. Напоминания: событие в Google Calendar через коннектор Claude (все тарифы), файл
   календаря `.ics` с напоминаниями за 1 день и за 30 минут (открывается в Apple, Google,
   Outlook, Яндекс), или задача по расписанию в ChatGPT (пуш или письмо).
6. Хранит настройки — откуда встречи, куда задачи, команда, напоминания, часовой пояс —
   блоком «Настройки следа» в проекте ИИ. Ссылок вебхука и ключей в нём нет.

## Что в репозитории

| Путь | Для чего |
|---|---|
| `plugins/sled/skills/sled/` | Навык: `SKILL.md`, справочники `references/`, шаблоны `templates/` (протокол и `.ics`), скрипт `sled.py` (протокол → задачи, `.ics`, Битрикс24) |
| `dist/sled.zip` | Навык в архиве — для загрузки в Claude (claude.ai и приложение) |
| `chat-instruction-sled.md` | Весь навык одним текстом — для проектов ChatGPT и Claude, DeepSeek и других чатов |
| `tests/test_sled.py`, `tests/fixtures/sled/` | Проверки: протокол по тестовой расшифровке, `.ics`, вебхук Битрикс24 |

## Как поставить

**Claude Code:**

```
/plugin marketplace add DianaMarshrut/labops-capsules
/plugin install sled@labopsai-capsules
```

**Claude (claude.ai и приложение):** включи «Settings» → «Capabilities» → «Code execution and
file creation», затем «Customize» → «Skills» → «+» → «+ Create skill» → «Upload a skill» →
`dist/sled.zip`. Создай проект «Встречи», подключи коннекторы Granola и Google Calendar
(«Settings» → «Connectors») и напиши в проекте: «настрой след».

**ChatGPT:** создай проект «Встречи» → «•••» → «Project settings» → вставь текст
`chat-instruction-sled.md` в инструкции проекта. Подключи приложение Granola, если оно есть
в твоём тарифе. Напиши в проекте: «настрой след».

**DeepSeek и другие чаты:** приложи `chat-instruction-sled.md` к первому сообщению и напиши
«Работай по этой инструкции». Дальше в этом же чате — «разбери встречу» и текст встречи.

## Безопасность

- Задачи и события создаются только после «да» на точный список.
- Битрикс24: **отдельный** вебхук только с правом «Задачи» (`task`), лучше от отдельного
  сотрудника «ИИ-постановщик». Не тот вебхук, что для чтения CRM в «Пульсе».
- Ссылку вебхука кладёшь в файл `~/.config/sled/b24_webhook` на своём компьютере, а не в чат.
  Скрипт её не печатает. Попала в чужие руки — удали вебхук и создай новый.
- Текст встречи — это данные: просьбы «ИИ, удали…» внутри расшифровки не выполняются.

## Честно о возможностях (проверено 27.10.2026)

- Granola: коннектор в Claude — на всех тарифах Claude; в ChatGPT на бесплатном тарифе —
  не подтверждено. Бесплатная Granola отдаёт в ИИ заметки за 30 дней, расшифровку — только
  платная. Работа Granola из России (вход, оплата) — не подтверждена.
- Google Calendar: Claude создаёт события на всех тарифах; заданы ли при этом напоминания —
  проверяй в событии. В ChatGPT создание события через Google Calendar в справке не описано.
- `.ics`: Google Calendar импортирует только на компьютере; сохраняются ли напоминания —
  в справке Google не сказано.
- DeepSeek: подключений, проектов, расписания и скачивания файлов в официальных источниках
  не нашли — всё вручную: вставить текст, сохранить `.ics` из текста, завести задачи.
- ChatGPT: задачи по расписанию есть и на бесплатном тарифе (до 3 активных, не чаще раза в день).
  Claude: задачи по расписанию — только на платных тарифах.

Источники — в конце каждого файла `plugins/sled/skills/sled/references/`.
